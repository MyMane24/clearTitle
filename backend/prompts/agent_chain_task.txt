STAGE: CONSTRUCT PROPERTY IDENTITY AND TITLE CHAIN.

You have been given the case documents (metadata + summaries). Investigate using
the tools, then persist the authoritative title chain.

Workflow:
1. Call `list_documents` to see every document in the case.
2. Inspect `get_document_metadata` and, where needed, `get_document_text` for the
   documents that carry title information. Follow references between documents.
3. Build the chronological title chain (oldest → newest) and the property
   identity.
4. Call `save_title_chain` EXACTLY ONCE with the full result.
5. Call `finish`.

`save_title_chain` expects:
{
  "property_identity": { "survey_number": "", "plot_number": "", "flat_number": "",
                          "location": "", "extent": "", "boundaries": "",
                          "additional_identifiers": {} },
  "transactions": [
    {
      "sequence": 1,
      "document_type": "SALE_DEED | ENCUMBRANCE_CERTIFICATE | ...",
      "transaction_type": "SALE | GIFT | PARTITION | RELEASE | MORTGAGE | RELEASE_OF_MORTGAGE | MUTATION | EC_ENTRY | OTHER",
      "executed_date": "raw date text or YYYY-MM-DD, or null",
      "registration_number": "or null",
      "registration_date": "or null",
      "vendors": ["seller names"],
      "purchasers": ["buyer names"],
      "party_locations": ["places"],
      "survey_number": "or null",
      "plot_number": "or null",
      "site_flat_number": "or null",
      "property_location": "or null",
      "market_value": "or null",
      "consideration": "or null",
      "schedule_property": "full schedule text or null",
      "conveyed_portion": "or null",
      "source_doc_ids": ["DOC_ID"],
      "inferred": false,
      "uncertainty": ["notes about uncertain links"]
    }
  ],
  "title_story": "plain-language narrative of the title from earliest to now",
  "unresolved": ["specific gaps or unanswered questions"]
}

Rules:
- Every transaction MUST cite at least one source_doc_id that exists in the case.
- Do NOT fabricate transactions. When a recital references a deed that is not
  present, still include the transaction, set `inferred: true`, and add an entry
  to `uncertainty` and `unresolved`.
- Order transactions chronologically (oldest first). `sequence` is display order
  only; ClearTitle assigns a stable internal id to each transaction.
- Never fabricate field values — use null / empty list / unknown.
