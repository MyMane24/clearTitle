Verify the Karnataka Sale Deed (SD) against the Encumbrance Certificate
(EC) historical ledger for the same property. The SD is the source of
truth for what was conveyed; the EC ledger must be consistent with it.

OUTPUT — You must return exactly these fields:

1. "verdict": Return exactly one of: CLEAR_TITLE or ATTENTION_REQUIRED.
Choose CLEAR_TITLE only when the complete report finds no unresolved discrepancy, subsequent transfer, active mortgage/encumbrance, title-chain gap, or other issue requiring investigation. If the headline or summary says the user must investigate, verify, obtain documents, or resolve a liability, return ATTENTION_REQUIRED.

2. "headline": A 2-3 line plain-language conclusion the user can read
in 5 seconds. Write it like a newspaper headline or case-study finding.
State the single most important finding. Do NOT use single words like
'VERIFIED' or 'NOT VERIFIED'. Explain WHAT was found and WHY in plain
English. For example: 'Sale Deed details match EC record, but the
property shows multiple subsequent sales and an active mortgage that
require investigation.'

3. "summary": A detailed verification report (2-3 paragraphs) that synthesizes ALL findings into one coherent conclusion. Cover:
   - What was checked (property identifiers, dates, parties, consideration)
   - What matched between SD and EC
   - What did not match or is missing
   - Title chain acquisition analysis: Cross-reference Vendor names in subsequent sales against prior Purchasers. If Vendors share family initials/names with a prior purchaser (e.g. 'G.' matching 'Gundappa') but no registered Partition Deed/Will is in the EC, explicitly state that the vendors appear to be legal heirs (wife/children), note the missing EC evidence, and advise inspecting physical Legal Heir Certificates, Death Certificates, and Khata mutation records.
   - Current Ownership & Encumbrances: State explicitly whether the purchaser named in the provided Sale Deed currently holds clear title or if title moved to subsequent buyers, and detail any active bank mortgages (Deposit of Title Deeds).
   - EC Recency & Next Steps: Check if the EC search end date is up to date; if old, recommend obtaining a fresh Encumbrance Certificate up to the current date. List exact offline/online documents the user should investigate.

Write for a non-legal audience. Do NOT end with a single-word verdict.
Instead, clearly state whether the title appears clear or has issues,
and explain why. If there are issues, describe what they are and what
the user should do about them.

4. "items": For each material field, produce one item with:
- field: the field name (e.g. 'Property survey/CTS number')
- sd_value: value extracted from the Sale Deed
- ec_value: value from the EC ledger (or 'Not found in EC')
- status: VERIFIED | FLAG | NEEDS_REVIEW | N/A
  VERIFIED: the value is present in both docs and matches exactly — and the notes describe NO problem
  FLAG: concrete discrepancy — values exist in both docs but don't match
  NEEDS_REVIEW: ambiguous — can't confirm from documents alone, needs human investigation
  N/A: field absent from both documents
- CRITICAL: status must AGREE with notes. If the notes mention any party missing from the EC, any value that does not match, or anything requiring investigation, the status CANNOT be VERIFIED — use FLAG (concrete mismatch) or NEEDS_REVIEW (uncertain). Never write a conclusion describing a problem and then mark the item VERIFIED.
- notes: brief explanation of why this status

Compare these fields: property identifiers (CTS/survey/plot numbers,
locality), execution/registration date, parties (vendors/purchasers),
consideration amount. Also check whether the EC shows any later
encumbrance (mortgage, sale, agreement) on the property AFTER the SD
date.

5. "overall_comment": A concise 1-paragraph (4-5 plain-language lines) final conclusion certificate for the PDF report. State clearly whether the title is clear/marketable or has critical title risks (such as subsequent transfers away from the SD purchaser, unverified legal heir transfers, or active bank mortgages), and summarize the single most important action the user must take.

RULES:
- If the EC property does not match the SD property at all, mark ALL
items as FLAG and explain clearly in headline + summary.
- Do NOT guess or hallucinate values. Use 'Not found in EC' if a value
is absent.
- The headline and summary are the final conclusion. They must reflect
ALL findings — field matches, chain gaps, legal heir ambiguities, subsequent sales, active encumbrances — not just field-level checks. A property can have all fields VERIFIED but still have a problematic title due to subsequent transactions or unverified family transfers.
- overall_comment MUST be a single concise paragraph of 4-5 lines specifically designed for Section 5 (Final Conclusion / Certificate) of the PDF report.
- The structured verdict must agree with the headline, summary, and overall_comment. Never return CLEAR_TITLE while describing unresolved title risks.
