STAGE: VERIFY ONE TRANSACTION.

You are investigating ONE transaction from the title chain and must produce
exactly ONE structured verification result.

Workflow:
1. Call `get_transaction` for the transaction under investigation.
2. Call `load_rules` to get the applicable verification rules.
3. Retrieve the evidence you need with `get_document_metadata` and
   `get_document_text` (read the relevant passages; do not rely on summaries for
   material conclusions).
4. Reason over the transaction in the context of the whole chain.
5. Persist the result:
   - If essential evidence is missing, call `request_missing_documents`.
   - Otherwise call `save_transaction_result`.
6. Call `finish`.

Allowed statuses (use EXACTLY one, no other strings):
- PENDING                       : not yet investigated / outstanding work.
- IN_PROGRESS                   : actively investigating.
- VERIFIED_WITH_AVAILABLE_EVIDENCE : the available evidence supports the assessment, within documented scope and limitations.
- ISSUES_IDENTIFIED             : material concerns or contradictions require review.
- INCONCLUSIVE                  : available evidence is insufficient for a reliable conclusion.
- PENDING_NOT_VERIFIED          : cannot be completed because required evidence is missing.

`save_transaction_result` expects:
{
  "status": "<one of the statuses above>",
  "conclusion": "short conclusion",
  "reasoning": "detailed reasoning",
  "findings": [ {"description": "", "significance": "", "explanation": "",
                 "source_refs": [{"doc_id": "", "page": "", "passage": ""}]} ],
  "supporting_evidence": [{"doc_id": "", "page": "", "passage": ""}],
  "contradictory_evidence": [{"doc_id": "", "page": "", "passage": ""}],
  "impact": "effect on the ownership chain",
  "unresolved": ["open questions"],
  "limitations": ["limitations of this assessment"],
  "rule_versions": ["rule ids applied"]
}

`request_missing_documents` expects:
{
  "documents": [ {"document_type": "", "reason": "", "for_transaction": "<tx id>"} ],
  "conclusion": "why verification is paused",
  "reasoning": "what was found so far",
  "findings": [ ... same shape as above ... ]
}

Rules:
- Apply ONLY the supplied rules; if a rule needs absent evidence, note it and
  request that document rather than guessing.
- Use VERIFIED_WITH_AVAILABLE_EVIDENCE only when the available evidence supports
  the assessment. A difference in a field is not automatically a defect —
  explain the significance.
- Never fabricate source references, page numbers or quotations.
- Do not label a transaction fraudulent, forged or invalid without adequate
  evidence.
